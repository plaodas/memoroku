# 開発の約束

実装計画の前に固定する約束です。計画とコードがここから外れるときは、先にこの文書を更新します。

いまの `ios/` と `android/` はスターターです。ウィジェットの実装方法は、この文書が優先します。

## プロダクト

memoroku は、短い録音メモのスマホアプリです。

録音する、音声を端末に残してアプリで再生できるようにする、アップロードする、文字起こしを待つ、できた短い文をホーム画面ウィジェットに出す。

## リポジトリ

memoroku はこのスマホアプリだけを置くリポジトリです。

文字起こしは `../minutes` のアップロードと文字起こしを API として使います。話者分け、要約、Word 出力は呼びません。二つのリポジトリは統合しません。

API の形の正本は、minutes の `docs/openapi.json` のうち memoroku が使う経路だけです。

## アプリとウィジェット

アプリ本体で録音し、端末に残し、再生し、アップロードし、完了を待ち、メモ一覧を出します。マイクの許可が済んでいるときは、最初から押しながら録音です。タップでの録音にも戻せます。録音中は、入ってきた音の大きさで波を動かします。押し始めが終わる前に指を離した回は、メモを作りません。

ウィジェットは、文字起こしが終わった短い文を表示します。録音ボタンは置きません。ウィジェットから minutes を呼びません。

文字起こしが終わったら通知します。ウィジェットをタップすると、そのメモをアプリで開きます。

iOS のウィジェットは `expo-widgets` と development build で作ります。Android のウィジェットは Glance で作り、config plugin からネイティブプロジェクトへ足します。

アプリからウィジェットへ渡すのは表示用のテキストです。iOS は App Group、Android は SharedPreferences を使います。

## メモの寿命

端末の SQLite にメモを保存し、24時間を過ぎたもの、または一覧から削除したものを消します。録音ファイルも同時に消します。表示中のメモが無くなれば、ウィジェットの文も空にします。

minutes のアップロードファイル保持は、既定で `UPLOAD_RETENTION_SECONDS=86400`（24時間）です。ユーザーが見返す文の置き場所は端末です。
