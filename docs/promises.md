# 開発の約束

実装計画の前に固定する約束です。計画とコードがここから外れるときは、先にこの文書を更新します。

いまの `ios/` と `android/` はスターターです。ウィジェットの実装方法は、この文書が優先します。

## プロダクト

memoroku は、短い録音メモのスマホアプリです。

録音する、音声を端末に残してアプリで再生できるようにする、アップロードする、文字起こしを待つ、できた短い文をホーム画面ウィジェットに出す。

## リポジトリ

memoroku はこのスマホアプリだけを置くリポジトリです。

文字起こしの既定は `../minutes` の `POST /api/transcribe-upload-bg` に `transcript_only=1` を付け、整形せず本文だけを受け取ります。設定で端末内に切り替えると minutes を呼ばず、端末に置いた多言語の Whisper Base（`ggml-base.bin`）で文字起こしします。話者分け、要約、Word 出力は呼びません。二つのリポジトリは統合しません。

API の形の正本は、minutes の `docs/openapi.json` のうち memoroku が使う経路だけです。

## アプリとウィジェット

アプリ本体で録音し、端末に残し、再生し、アップロードし、完了を待ち、メモ一覧を出します。マイクの許可が済んでいるときは、最初から押しながら録音です。タップでの録音にも戻せます。初回だけ、録音ボタンの上に「タップで開始、もう一度で終了」と「押しながら録音もあります」を出します。Android のアイコン長押しの「録音」は、許可済みなら起動と同時に録音を始め、その回だけタップ録音にします。録音中は、入ってきた音の大きさで波を動かします。押し始めが終わる前に指を離した回は、メモを作りません。

ウィジェットは、文字起こしが終わったメモを最大8件、各先頭15文字で表示します。残したメモを優先し、空いた行に新しいメモを出します。Android は高さに入る行だけ出し、ウィジェット内ではスクロールしません。録音ボタンは置きません。ウィジェットから minutes を呼びません。

文字起こしが終わったら通知します。ウィジェットの行をタップすると、そのメモをアプリで開きます。

iOS のウィジェットは `expo-widgets` と development build で作ります。Android のウィジェットは Glance で作り、config plugin からネイティブプロジェクトへ足します。

アプリからウィジェットへ渡すのは表示用のテキストです。iOS は App Group、Android は SharedPreferences を使います。

## メモの寿命

端末の SQLite にメモを保存します。通常のメモは24時間で消します。カードの「残す」にしたメモは、手動で削除するか、「残す」を解除するまで残します。解除した時刻から24時間後に消します。消すとき録音ファイルも消します。表示中のメモが無くなれば、ウィジェットの文も空にします。

minutes のアップロードファイル保持は、既定で `UPLOAD_RETENTION_SECONDS=86400`（24時間）です。ユーザーが見返す文の置き場所は端末です。
